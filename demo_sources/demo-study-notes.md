# Demo Study Notes

Mini NotebookLM helps students ask questions over selected course sources.

The MVP supports three source paths for the demo: PDF upload, TXT/MD upload,
and pasted text. Retrieval only uses sources that are currently enabled in the
notebook, so disabling a source should remove it from future answers and
citations.

For the Project I demo, the clearest success signal is an answer with a
clickable citation that opens the evidence panel and shows the original chunk.
Chat history should still appear after refreshing the browser.
